# Security Policy

## Supported versions
Security reports are handled on the latest repository revision. This community project has no formal response-time guarantee.

## Reporting a vulnerability
Do not publish exploitable details in a public issue. Use GitHub's private vulnerability reporting feature if enabled, or contact the maintainer through the GitHub profile.

Include the affected version, impact, reproduction steps, and sanitized logs.

## Safe use
Only connect to devices you own or are authorized to administer. SDB shell commands can change device state or data. Review commands before execution and maintain backups.
